🧠 会话与上下文管理

/new

功能：开始一个全新的对话，完全清除当前聊天历史

使用示例：

使用场景：

  1. 切换话题：当前话题已完成，需要开始全新的对话
  2. 上下文清理：对话历史过长，需要清理上下文窗口
  3. 隐私保护：确保前一个会话的信息不会泄露到新会话

注意事项：

  • 该操作不可逆，之前的对话历史无法恢复
  • 会保留基本的系统配置和技能记忆
  • 建议在重要对话前先使用/export_session备份

/revert 或 /reset

功能：重置当前会话，清空上下文重新开始

使用示例：

或

与/new的区别：

  • /new：完全重新开始，创建全新的会话
  • /revert或/reset：在当前会话中清空历史，但保持会话ID

使用场景：

  • 当前对话偏离主题，需要重新开始
  • 测试不同输入对同一问题的回答
  • 清除敏感信息后继续对话

/compact

功能：压缩当前会话内容，将早期对话总结成摘要，释放上下文空间

使用示例：

工作原理：

  1. 分析当前会话历史
  2. 将早期对话内容提炼为简洁摘要
  3. 用摘要替换原始长对话
  4. 释放上下文窗口空间给新对话

使用场景：

  • 长时间对话导致上下文窗口接近满时
  • 需要保留早期对话要点但不需完整历史时
  • 优化性能，减少token消耗

注意事项：

  • 压缩过程是智能的，会保留关键信息和决策点
  • 压缩后无法恢复原始完整对话
  • 建议在重要节点先导出会话备份

/export_session

功能：导出当前会话的数据，用于备份或迁移

使用示例：

输出格式：

  • JSON格式，包含完整会话历史
  • 包含时间戳、参与者、消息内容
  • 可选包含附件和工具调用记录

使用场景：

  1. 备份重要对话：项目讨论、决策记录等
  2. 迁移会话：在不同设备或实例间转移对话
  3. 分析对话：用于训练数据或行为分析
  4. 合规要求：某些场景需要保留沟通记录

文件保存：
导出的文件通常保存为：

  • session_export_<timestamp>.json
  • 可选择保存路径或直接复制到剪贴板

/context

功能：解释当前命令的上下文是如何绑定的（调试用）

使用示例：

输出内容：

  • 当前会话ID和创建时间
  • 绑定的频道信息（Telegram、Discord等）
  • 上下文窗口使用情况
  • 当前生效的配置和技能

使用场景：

  • 调试上下文绑定问题
  • 理解当前会话的状态
  • 排查为什么某些功能不可用
  • 开发者调试多频道集成

/steer

功能：给正在运行的子智能体发送新的指引，调整它的任务方向

使用示例：

工作原理：

  1. 查找指定的子智能体
  2. 将新的指引信息插入到它的上下文中
  3. 智能体会根据新指引调整执行方向

使用场景：

  • 任务优先级发生变化时
  • 发现更好的执行策略时
  • 需要调整任务范围或目标时
  • 纠正偏离方向的子任务

优势：

  • 避免强制停止后重新开始
  • 保留已有工作成果
  • 更平滑的任务调整

<任务描述>

功能：在当前会话中执行一个独立任务，不影响主对话上下文

使用示例：

说明：
这不是一个斜杠命令，而是一种任务委托方式。当你直接描述一个任务时，OpenClaw会：

  1. 创建一个临时的任务上下文
  2. 执行指定任务
  3. 完成后在主对话中报告结果
  4. 清理临时上下文

特点：

  • 任务执行不影响主对话历史
  • 适合一次性分析或处理任务
  • 完成后自动清理，节省上下文空间

🛑 控制与停止

/stop

功能：停止当前正在进行的生成或任务

使用示例：

可停止的操作：

  • 长时间运行的模型生成
  • 文件处理任务
  • 网络请求
  • 子智能体执行

工作方式：

  1. 向当前任务发送停止信号
  2. 等待任务安全停止（如果可能）
  3. 清理相关资源
  4. 报告停止结果

使用场景：

  • 生成结果不满意，需要重新生成时
  • 任务执行时间过长时
  • 发现任务方向错误时
  • 需要立即释放资源时

/restart

功能：重启 OpenClaw 服务（需要相应权限）

使用示例：

重启过程：

  1. 保存当前所有会话状态
  2. 优雅停止所有服务
  3. 重新加载配置和插件
  4. 恢复会话状态
  5. 报告重启完成

使用场景：

  • 配置变更后生效
  • 插件安装或更新后
  • 解决服务卡住或异常
  • 定期维护重启

权限要求：

  • 需要/elevated权限或管理员角色
  • 重要环境可能需要额外的确认
  • 重启会影响所有在线用户
